# Repository workflow

- Use `newdesign` as the working branch for this repository. Do not create another branch unless the user explicitly asks for one.
- Keep an open pull request from `newdesign` to `main` while changes are in progress. If that PR is merged or closed, sync `newdesign` with `main` and open the next PR from `newdesign` when there are new changes to review.
- Commit and push completed work to `newdesign`. Before saying a change is in a PR, verify that the PR is open and its head includes the pushed commit.
- Preserve existing work and history. Do not force-push, reset, or discard unrelated changes to maintain this workflow.
